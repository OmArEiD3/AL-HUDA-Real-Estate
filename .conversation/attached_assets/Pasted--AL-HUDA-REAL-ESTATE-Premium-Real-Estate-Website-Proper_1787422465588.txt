# AL HUDA REAL ESTATE

## Premium Real Estate Website + Property Management Admin Dashboard

Build a production-quality, premium real estate website and a secure property management dashboard for:

**AL HUDA REAL ESTATE**
**الهدى العقارية**

Primary market:

**Sheikh Zayed City, Egypt**

The system must consist of two connected parts:

1. Public Customer Website
2. Secure Admin Dashboard

The public website is for customers searching for properties.

The Admin Dashboard is for authorized AL HUDA staff to manage properties, images, videos, descriptions, prices, statuses, locations, and leads.

The entire system must be designed as a real production application, not a static demo.

---

# 1. CORE ARCHITECTURE

Use a scalable architecture.

Recommended:

Frontend:
React / Next.js or Lovable's recommended production stack.

Backend:
Supabase or an equivalent production backend.

Use:

* PostgreSQL database
* Authentication
* Storage
* Row Level Security
* API/data layer
* Realtime updates where useful

The exact implementation can use the best native Lovable-compatible architecture.

IMPORTANT:

Do not build the property system using hard-coded frontend arrays.

Properties must come from the database.
